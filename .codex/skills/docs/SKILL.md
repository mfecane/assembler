# Documentation

- Keep knowledge base for quick context for code agents.

- Keep knowledge base tidy and well organized. Keep reasonable folder structure.

- Keep files inside docs folder structured by folders.

- Keeps docs indexed in main docs/index.md for quick lookup.

- Document
    - Functionality
    - Architecture
    - UX flows
    - Database schema
    - Data model
    - Current application state
    - Planned functionality
    - TODO's
    - Code reviews
    - Ad-hoc docs

- When working on certain big feature, document implemtation plan

- Check and clean up obsolete doc files.

- Review files regularly to keep them up to date.
