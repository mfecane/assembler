Rebuild inputs dialog.

Inputs are placed as nodes, not via the dialog.

Dialog does exist only to build ui configuration panel - map inputs to configutation dialog ui elements, choose element type from compatible ones, configure ui element. I.e. as configuration panel's editor. Display only for root graph.

The runtime configuration panel uses an even label/control grid and can be collapsed from its
header. Its collapsed state is view-only and is not persisted in the graph document.
